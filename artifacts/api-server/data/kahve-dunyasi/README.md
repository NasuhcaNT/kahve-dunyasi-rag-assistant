# Yerel bilgi tabanı klasörü

Çalışma zamanında kullanılan `clean_documents.jsonl` ve `clean_chunks.jsonl` dosyalarını bu klasöre yerleştirin.

Gerçek veri dosyaları üçüncü taraf içerik hakları ve kaynak kullanım koşulları nedeniyle Git tarafından izlenmez. Yalnızca toplama, saklama ve kullanma yetkiniz bulunan verileri ekleyin. Sentetik şema örnekleri için `examples/knowledge-base/` klasörüne bakın.
