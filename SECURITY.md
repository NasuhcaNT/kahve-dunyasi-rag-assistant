# Güvenlik politikası

Güvenlik açığı veya yanlışlıkla yayımlanmış bir sır fark ederseniz bunu herkese açık bir issue içinde paylaşmayın. Depo sahibine GitHub profilindeki özel iletişim kanalı üzerinden bildirin.

API anahtarları, `DATABASE_URL`, erişim belirteçleri ve gerçek kullanıcı verileri Git'e eklenmemelidir. Bir sır yanlışlıkla yayımlandıysa yalnızca dosyadan silmek yeterli değildir; ilgili anahtar derhal iptal edilip yenilenmelidir.
